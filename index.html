TMS99105 Single Board Computer projects

A homebrew single board computer built around the Texas Instruments TMS99105, the last of the TMS9900 family, along with the operating system, tools and compiler that run on it.

SMALLC99: a native C compiler for the TMS99105

A Small-C compiler with structs, unions, multi-dimensional arrays and multi-level pointers that runs on the SBC itself. It fits in 64K by swapping eight overlays through paged memory. Source on GitHub.

TMS99105 SBC

The hardware: schematics, memory structure, disc monitor, and the board's history from an S100 wire-wrap system onwards.

Transparent paged memory system

A memory mapper giving the TMS99105 access to 1MB of RAM through sixteen 4K segments, with an overlay manager.

BDOS for the TMS9900

A small disk operating system with CP/M-style interfaces and folder support, written for the paged SBC.

Small Shell

The command interpreter that runs .COM, .EXE and procedure files on top of BDOS.

R99 assembler and LINK99 linker

A relocating assembler and linker for the TMS9900/99000, producing flat and paged overlay binaries.

Small C Plus for the TMS9900/99000

A Small C Plus compiler for the TMS9900 with floating point, structures and unsigned types.
